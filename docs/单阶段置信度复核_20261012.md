# 单阶段置信度筛选与证据复核

当前流程：Qwen 初判并保存 → 按初判类别概率筛选 → 一次独立模型证据复核 → 程序接受改判或保留初判。

“两阶段入口”是已删除的先独立提取要求、再独立校验答案的两次模型调用流程。本地与API是运行后端选择，两个选择继续保留，均执行当前单阶段流程。API明确选择deepseek-flash；本地明确选择Linux／WSL2下的独立vLLM模型，原生Windows使用API复核。置信度筛选、正文输入、边界提示词、证据合同和程序接受规则在两个后端共用；本地vLLM顺序处理，API本次并发5。

high／medium 的对应概率低于 0.9，或 low 的对应概率低于 0.7，才复核。等于阈值时跳过。概率缺失或无效时送审。三类 softmax 数值尚未校准，阈值不能解释为真实正确率。

一次复核接收原文、题目、评论和完整答案，不接收 Qwen 初判、置信度、参考标签或样本 ID。文档问答的 null 评论原样保留。模型在同一次调用中识别必要要求、核验答案、引用证据、诊断理解修复方向并给出一个等级；没有独立要求提取调用，也不声称要求清单是盲提取。

| 等级 | 实质条件 | 修复方向 |
|---|---|---|
| high | 核心理解正确、关键陈述有依据、完成全部题目必要要求 | 无需实质修复 |
| medium | 已有实质正确理解、无核心误读，但有题目要求内的真实不足 | 保留正确理解补充、澄清或收窄 |
| low | 核心对象、立场、观点归属、关键关系或价值含义发生实质误读 | 改变中心解释或结论 |
| low 的无回答情形 | 材料足以回答，但纯拒答、不知道或完全偏题且没有有效理解 | 重建回答 |

不按长度、关键词、修辞性犹疑、可选背景或修改字数降档。合理蕴含算覆盖，不能替答案补出未表达的理解。真实材料歧义允许合理不确定性。

程序检查必要要求的题目／材料依据、逐字引用、覆盖清单、具体不足及修复方向是否一致。这些是结构与证据真实性检查，不能证明语义判断正确。无效、不完整、超时或服务失败均保留有效初判，每个送审样本最多一次复核尝试。

按用户要求，不再使用旧默认配置；明确选择config.current.local.json或config.current.server.json，使用本次实验参数和mode=experimental，接受通过上述检查的改判。calibrated仍需独立验证过且匹配版本的改判策略。新规则没有自动保证ACC的性质。

单阶段采用 schema 3 和 single_call_boundary_gate_v3。更换调用协议后新建结果目录，可复用有明确来源的初判缓存；原数据、旧初判及旧复核记录均保留。已有复核不能冒充新协议结果。API 和离线 vLLM 使用同一单阶段提示词及门控。

本次明确配置 `review_max_new_tokens=4096`、API超时120秒、并发5、requests持久连接及模型列表预热。截断时仍保留初判。其他服务可明确选择 `review_api_transport=curl`（系统需有curl）或urllib，均不关闭证书核验。模型和路径必须由对应任务配置或命令行明确指定。

最终实验目录：`experiments/single_review_deepseek_newkey_600_1533_20261012/`。完整600条和1533条均不运行Qwen，分别送审204条和264条。600条缓存初判使用旧评论占位，而复核使用现有null评论，报告明确该差异；1533条四个输入字段完全匹配。两批分别统计初判、整体复核后ACC、各类召回、纠正／改错及失败，不按结果调阈值或修改标签。600条标签未独立核实，两个数据集均属于已使用过的回顾性数据。

按用户要求，本次不进行代码审查或运行测试套件。实际模型实验和结果统计不属于测试套件。

最终实验已处理完：600条复核解析成功203/204，1533条成功263/264，失败均保留初判。600条ACC从71.50%升至84.67%，纠正90条、正确改错11条；1533条从91.00%降至89.17%，纠正45条、正确改错73条。1533条主要误改为medium→high。本次按用户要求明确使用experimental接受方式，该选择不意味着已经独立校准或能保证ACC。

600条耗时228.3秒，1533条耗时360.8秒，API并发5，均不含历史Qwen推理。实际模型POST为467次，另有1533条一次连接预热失败的复核尝试；468条送审均已处理，包括失败。原DeepSeek网络失败及GLM参数拒绝记录独立保留，不作为成功实验。完整结果见 [报告](../experiments/single_review_deepseek_newkey_600_1533_20261012/report.md)。
