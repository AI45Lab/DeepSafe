Overview

项目亮点Highlights

当前大模型安全评测缺乏全面的标准化方案，且普遍缺失专用评测模型。为此，我们发布 DeepSafe—聚焦 10 个核心安全 benchmark 与 ProGuard 评测能力的一体化展示，支持LLM/VLM评测，构建模块化解耦+配置驱动的弹性架构，实现从推理生成判断到深度评测报告的全链路自动化闭环。通过该静态版本，我们保留所选 benchmark 的原站介绍与榜单内容，提供可复查、可发布的 GitHub Pages 页面，旨在推动大模型安全评估从结果测试走向深度分析，加速构建可信AI的评测进程。Safety evaluation for large models currently suffers from a lack of standardized protocols and dedicated assessment tools. We present DeepSafe, an all-in-one framework focused on 10 selected safety benchmarks and the specialized ProGuard evaluation capability. DeepSafe supports multimodal LLM/VLM evaluation through a modular, configuration-driven architecture that automates the entire workflow from inference to deep reporting. This static version preserves the original introduction and leaderboard content for the selected benchmarks in a GitHub Pages friendly form. It is designed to advance large-model safety evaluation from outcome-based testing to rigorous analysis, accelerating the development of trustworthy AI evaluation.
