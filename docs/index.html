Overview

项目亮点Highlights

当前大模型安全评测缺乏全面的标准化方案，且普遍缺失专用评测模型。DeepSafe 提供标准化 benchmark 与 ProGuard 评测能力，支持 LLM/VLM 评测，采用模块化解耦与配置驱动架构，实现从推理生成、裁判评估到报告可视化的自动化闭环。页面整理了 benchmark 的介绍、评测方法、指标和榜单，方便研究者复查模型在关键安全场景中的表现，并推动大模型安全评估从结果测试走向深度分析。Safety evaluation for large models still needs standardized protocols and dedicated assessment tools. DeepSafe provides safety benchmarks together with ProGuard evaluation capability for LLM/VLM assessment, using a modular and configuration-driven architecture to automate inference, judge-based evaluation, and report visualization. These pages organize benchmark introductions, methods, metrics, and leaderboards so researchers can review model behavior across critical safety scenarios and move safety evaluation from outcome testing toward deeper analysis.

Usage Guide

如何使用 DeepSafeHow to Use DeepSafe

DeepSafe 的标准流程分为配置、推理、评估和可视化四步。下面的命令和 YAML 片段来自项目 README，可作为首次跑通 Salad-Bench 的参考。DeepSafe follows a four-stage workflow: configure, inference, evaluation, and visualization. The commands and YAML below are adapted from the project README and can be used to run Salad-Bench end to end.

Step 1

准备环境Environment

建议在虚拟环境中安装依赖，并用 smoke test 确认基础组件可用。Install dependencies in a virtual environment and run the smoke test to verify the setup.

pip install -r requirements.txt
pip install -U huggingface_hub
python smoke_test.py
Step 2

准备数据集Datasets

多数评测数据集托管在 Hugging Face。下载后，在对应 YAML 中把 dataset.path 指向本地文件。Most evaluation datasets are hosted on Hugging Face. After downloading, point dataset.path in the YAML file to the local file.

huggingface-cli download --repo-type dataset \
  --resume-download OpenSafetyLab/Salad-Data \
  --local-dir Salad-Data \
  --local-dir-use-symlinks False
Step 3

配置裁判模型Judge Model

Salad-Bench 可使用 MD-Judge-v0.1。下载权重后，把 evaluator.judge_model_cfg.model_name 改成本地路径，并按显存设置 TP 与显存占用。Salad-Bench can use MD-Judge-v0.1. Download the weights, set evaluator.judge_model_cfg.model_name to the local path, and tune TP and GPU memory settings.

huggingface-cli download --resume-download \
  OpenSafetyLab/MD-Judge-v0.1 \
  --local-dir MD-Judge-v0.1 \
  --local-dir-use-symlinks False
Step 4

启动评测Run Evaluation

在项目根目录执行任务脚本。流程会生成模型回答、调用评测器打分，并汇总指标。Run the task script from the project root. It generates model responses, invokes the evaluator, and aggregates metrics.

bash scripts/run_salad_local.sh \
  configs/eval_tasks/salad_judge_local.yaml
YAML

参考配置片段Reference Config

路径需要按本地实际位置修改。常用参数包括 model.type、model_name、api_base、concurrency、strip_reasoning、temperature、max_tokens、dataset.type、dataset.path、dataset.limit、evaluator.type、template_name、judge_model_cfg、metrics.type 和 runner.output_dir。Adjust paths for your machine. Common fields include model.type, model_name, api_base, concurrency, strip_reasoning, temperature, max_tokens, dataset.type, dataset.path, dataset.limit, evaluator.type, template_name, judge_model_cfg, metrics.type, and runner.output_dir.

dataset:
  type: SaladDataset
  path: /your/path/to/Salad-Data/base_set_sample_100.json

evaluator:
  type: ScorerBasedEvaluator
  batch_size: 32
  template_name: md_judge_v0_1
  judge_model_cfg:
    type: VLLMLocalModel
    model_name: /your/path/to/MD-Judge-v0.1
    tensor_parallel_size: 1
    gpu_memory_utilization: 0.4
    trust_remote_code: true
    temperature: 0.0
    max_tokens: 64
Output

查看结果Outputs

评测完成后，输出目录会保存模型回答、预测/打分结果、样本记录和可读的 report.md 报告。After evaluation, the output directory contains responses, predictions or scores, sample records, and a readable report.md.

Benchmarks

Benchmark SuiteBenchmark Suite

每张卡片进入对应详情页，包含介绍、评测方法、指标和榜单。卡片标签仅保留最相关的一到两个安全风险维度，包括偏见歧视、违规违法/有害内容、恶意指令/越狱攻击、伦理/价值、幻觉/误导、前沿欺骗性风险和交互操控。Each card opens a detail page with the introduction, evaluation method, metrics, and leaderboard. Card tags keep only the one or two most relevant safety-risk dimensions, including bias and discrimination, illegal or harmful content, malicious instructions and jailbreaks, ethics and values, hallucination and misleading behavior, frontier deceptive risks, and interaction manipulation.
